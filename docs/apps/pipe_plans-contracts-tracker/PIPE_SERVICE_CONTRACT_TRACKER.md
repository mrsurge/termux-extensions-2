## Decisions

| Status   | Decision                                                      | Outcome                                                                                                            |
| -------- | ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| done     | Contract before transport                                     | Existing producers/consumers adopt DTOs before stdout pipe cutover.                                                |
| done     | stdout reserved for protocol                                  | All logs go to stderr.                                                                                             |
| done     | Request id and NID are separate                               | `id` routes response; NID routes participant lanes.                                                                |
| done     | Use `projectGeneration` for stale rejection                   | Prevents project-switch stale results from applying.                                                               |
| done     | WBA language intelligence stays out of this pipe              | Only watcher/file-change normalization is in scope.                                                                |
| done     | Old event-bus tracker is historical                           | Do not carry old phases forward as active architecture work.                                                       |
| done     | GitPython/pygit2/git2 are implementation details              | The active target is the `service.git` pipe boundary; Rust uses `git2`/libgit2 for the current framework provider. |
| done     | Store authority remains in existing app stores for this phase | Pipe services return operation DTOs; they do not own app preference/history/sidecar truth yet.                     |
| done     | Search materialization stays Python-owned                     | Rust produces search results and terminal counts; Explorer `more` and `moreInFile` are backend cache materialization methods, not Rust pipe provider methods. |
| todo     | Repo-wide replace is preview/apply, not editor find widget    | Monaco active-file find/replace stays on editor/UI IPC. Repository replace belongs to `service.search` preview/apply DTOs with explicit user selection and conflict reporting. |
| deferred | Full persistence service for sidecars/preferences/history     | Not part of initial fs/git/os pipe cutover.                                                                        |
