## Architectural Nuances To Preserve

- [created: a3b7e8e9] `code_te2` is canonical; aliases never create another worker/
  catalog identity. `TE2_*_HOME` are final roots, otherwise XDG plus `/te2`; source
  and app-state partitions differ. Legacy recovery is explicit, not startup repair.
- [created: a3b7e8e9] Rust framework is authority; retained Python CLI/console/MCP/
  app domains are intentional. Do not restore the retired Python framework.
  Routine traffic must not scan `/proc` or rediscover every FWS record; use exact hot-path capabilities.
- [created: a3b7e8e9] Code TE2 runs bootstrap-selected raw `CODE_TE2_WORKER_BIN`;
  PyO3 domain policy differs from native I/O. Pipe `app.readiness` follows startup/
  listener bind; no HTTP/shell-probe substitute. Metadata isn't live pipe ownership.
  Compiled launch contexts must be suspension-free; imports don't prove restart parity.
- [created: a3b7e8e9] Sidecars own membership/drafts; stable `clientInstanceId` owns
  foreground. `windowId` is metadata, `last_file` migration seed. Shared Sidebar
  membership differs from client order/visibility; incomplete snapshots don't
  prune, and replay cannot reveal hidden views. No global-active/broadcast fallback.
- [created: a3b7e8e9] Cross-surface intent: frontend → own backend → target hook →
  notification. Intelligence/diagnostics go directly to WBA; Python diagnostics
  project Explorer/Problems only. Visible open completion is independent of WBA ack.
- [created: a3b7e8e9] `webWorkersEnabled` selects exclusive browser-worker/private
  managed Code Server mode; no silent fallback/system/PATH runtime authority.
  WBA sends require initialized extension-host handshake, not just a socket/process.
- [created: a3b7e8e9] TextMate catalog/revision/ID/hash stays backend-authoritative.
  Matching packaged/verified IndexedDB bodies precede native chunk RPC or guarded
  browser HTTP; plain-HTTP SHA-256 fallback works. Storage failures are misses;
  transport failures don't switch routes. Keep exact-client first-model and
  cross-file/disconnect fences; snippets add no WBA models.
- [created: a3b7e8e9] Historical Git views are immutable/outside WBA; Restore is
  consent/identity/SHA guarded and preserves index/HEAD. Index facts, comparison
  appearance and retained hits differ. Never retry an uncertain mutation.
- [created: a3b7e8e9] Authored UI uses app-owned controls/async teUI, not native
  selects/prompts. Keep JSON fields/autocapitalization off, including sticky inputs.
  Preserve Android guarded input, focused-realm/touch/read-only ownership.
  Supported keyboard baseline is Gboard 18+, not runtime keyboard detection.
- [created: a3b7e8e9] Terminal owners differ: standalone Node/headless-xterm;
  Code TE2 native PTY/Pyte; File Explorer's own Node PTY worker, shellspec/codec/
  build with neutral projection. File Explorer is an ordinary Python worker,
  not a Code TE2 bridge consumer. Never share another app's backend/shellspec.
  New xterm PTYs use `TERM=xterm-256color`; resize doesn't recreate healthy streams.

## Transport Cheat Sheet

- [created: a3b7e8e9] `/api/app/code_te2/socket.io`: editor `/rpc/editor`, Explorer
  `/rpc/explorer`, host `/ui_ipc`, Sidebar `/sidebar_ipc`, drawer `/terminal`.
- [created: a3b7e8e9] `/api/app/code_te2/services/wba/socket.io`, `/wba`: direct
  intelligence. `/te2_console_ws/socket.io`, `/te2_console`: runtime observability.
- [created: a3b7e8e9] App editor/Explorer/host/Sidebar try polling then WebSocket;
  WBA/terminal stay WebSocket-only. Editor optionally negotiates `msgpack-gzip-v1`
  (raw requests/native compressed replies); legacy `msgpack-v1` and other codecs
  remain. HTTP asset gzip, RPC gzip and OTA ZIP are distinct.
- [created: a3b7e8e9] Requests require connection; notifications are volatile.
  Disconnect rejects pending/async work; reconnect reconstructs state. No JSON
  fallback, Socket.IO recovery, stale editing queue or uncertain mutation replay.
  Framework/WBA pipes differ; keep stdout protocol-only and upgrade matched peers.
- [created: a3b7e8e9] Pipe intents require allowlisted client/presentation/project
  identity; no missing-identity full-page fallback. `teFetch` already unwraps
  `body.data`. File Explorer tabs/path/shell authority is backend-owned, not Sidebar.
