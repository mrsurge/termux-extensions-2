    Enable LSP Integration
    When enabled, opening a supported file will start its language server in a Framework Shell (used for sticky scroll scopes today, and diagnostics/completions later).
    Available Servers
    Pyright
    .py, .pyw — Python type checking & analysis
    TypeScript Language Server
    .js, .jsx, .ts, .tsx — JavaScript & TypeScript
    clangd
    .c, .h, .cc, .cpp, .cxx, .hpp — C & C++ (Termux/Ubuntu package)
    Kotlin LSP (JetBrains)
    .kt, .kts — Kotlin (vendored)
    Android Kotlin LSP (Gradle)
    .kt — Android diagnostics via Gradle compile

    Note: Changes take effect when you open a new file of the corresponding type.
